# Curso OO - Full Cycle Juniors

## Ações do repositório

- Versão do Node utilizada:

  - `v22.21.1` a LTS `jod`
  - Está especificada no arquivo `.nvmrc`, então, caso utilize o NVM, basta rodar o comando `nvm use` na raiz do projeto para utilizar a versão correta.

- Dependências:
  - TypeScript.
    - Instalado com: `npm install --save-dev typescript`
  - TSX.
    - Instalado com: `npm install --save-dev tsx`
